# vibe-stick CoreS3

키보드 없이, 누르고 말로 시키는 Claude Code 리모컨. *(English: [README.md](README.md))*

M5Stack CoreS3 를 **화면을 눌러 Claude Code 에 말로 지시하는 기기**로 만든다. USB 선 하나로 맥에 "키보드 + 마이크"로 잡히고, 선을 뽑으면 버튼만 블루투스 키보드로 간다. 음성 인식은 Claude Code 의 받아쓰기(⌘D)를 그대로 쓴다.

![모든 장면](docs/design/cores3-screens.png)
*모든 장면(기기 픽셀 그대로). 아이콘은 그림 생성 스크립트(`cores3/tools/gen_art.py`)가 그린 선 그림이다. 기본 캐릭터는 Claude Code 캐릭터의 비공식 팬 아트로 MIT 의 예외다 — [마스코트](#마스코트) 참고.*

*Anthropic 과 무관한 비공식 개인 프로젝트다 — 맨 아래 [비공식 프로젝트](#비공식-프로젝트).*

## ⚠️ 먼저 읽을 것 — 위험 안내

**펌웨어는 이 저장소(<https://github.com/parkds-claude/vibe-stick-cores3>)의 소스로 직접 빌드하고, 다른 곳에서 받은 바이너리는 굽지 않는다** — 고친 펌웨어는 만든 사람이 원하는 것을 치는 키보드다. 배포판(Release)과 빌드된 펌웨어는 없다. 보안에 대한 안내와 문제를 알리는 길: [SECURITY.md](SECURITY.md).

이 기기는 **키보드**다. 꽂은 컴퓨터(선을 뽑으면 짝 맺은 컴퓨터)에 Enter·Esc·⌘D 를 보낸다. 그리고 Enter 는 Claude 의 "이 파일 고쳐도 돼?" 창을 **승인**한다.

- **누르기 전에 컴퓨터 화면을 본다.** 기기는 컴퓨터 화면을 모른다. 커서가 편집기(파일)에 있으면 ⌘D 와 Enter 가 파일로 들어간다.
- **남의 컴퓨터에 꽂지 않는다.**
- **블루투스 짝은 믿을 수 있는 곳에서 맺는다.** 숫자 확인이 없는 방식이라, 짝이 없는 동안(처음 · 짝을 지운 뒤)에는 먼저 붙는 컴퓨터가 짝이 된다.
- **잃어버리면 맥의 블루투스 목록에서 `vibe-stick S3` 를 지운다.** 기기 안의 것은 암호화돼 있지 않아, 기기를 손에 넣은 사람은 맥과 맺은 짝의 열쇠를 꺼내거나 다른 펌웨어를 구울 수 있다.
- **올리려 한 적이 없는데 `Update firmware? Hold OK` 가 뜨면 ✕ 를 누른다.** 펌웨어는 ✓ 를 꾹 눌러야 바뀐다.
- **개발판(`tools/flash.sh --dev`)을 올려 둔 채 쓰지 않는다.** 컴퓨터의 아무 프로그램이나 이 기기에게 키를 치게 할 수 있는 판이다. 개발판은 평소 화면 맨 위에 자홍·검정 띠가 보인다.
- **처음 올리기 전에 기기의 원래 내용을 백업한다.** 백업에는 예전 펌웨어의 와이파이 비밀번호 같은 것까지 담긴다. 저장소 밖에 두고 남에게 주지 않는다.

더 자세한 것은 [docs/사용법-cores3.md](docs/사용법-cores3.md) 의 "보안에 대해 알아 둘 것"과 [SECURITY.md](SECURITY.md).

## 한눈에

- **클로드에 리모컨을 달았다.** 누르고 말로 시킨다 — 키보드 없이. 선을 뽑아도 블루투스로 붙는다(그때는 버튼만 간다).
- **누르고, 말로 시킨다.** 커서를 Claude 입력창에 두고 말하면 VS Code 의 Claude Code 가 받아쓴다. OK 를 누르면 그대로 보내진다.
- **"고쳐도 돼?" 엄지로 답한다.** 맥 화면을 보고 허락이면 OK, 아니다 싶으면 ✕ — 키보드에 손이 안 간다.
- **선을 뽑고 멀리서 눌렀다.** 만든 사람이 20m 떨어져 눌러 봤다. 버튼은 닿는다 — 다만 물음은 기기에 뜨지 않으니 맥 화면을 보고 누른다. (닿는 거리는 곳에 따라 다르다.)
- **선을 꽂으면 기기가 마이크다.** 맥의 소리 입력에서 `vibe-stick mic` 을 고르면 기기에 대고 말한다 — 마이크 없는 맥에서도. 무선일 땐 맥 쪽 마이크(맥의 마이크나 이어폰)가 듣는다.
- **이 네모의 정체, M5Stack CoreS3.** 54mm 정사각에 2인치 터치 화면. 마이크 · 스피커가 들어 있다. 배터리(500mAh)는 뒤에 붙는 받침에 들어 있다 — 함께 오는 DinBase 에도 들어 있고, 만든 사람은 그 자리에 더 얇은 M5GO Battery Bottom3 를 달았다. (배터리가 없는 CoreS3 SE 로는 확인하지 않았다.)
- **누르는 곳은 화면에 일곱 군데.** Talk · OK · Back · Next 큰 타일 넷, 그 위에 위 · 아래 · 취소(▲ ▼ ✕) 작은 타일 셋.
- **이 리모컨, 오픈소스다**(MIT — 기본 캐릭터만 예외, [마스코트](#마스코트) 참고). 납땜 없이, 이 소스로 펌웨어를 직접 빌드해 구우면 된다(완성된 펌웨어 파일은 배포하지 않는다). 만드는 법은 [docs/사용법-cores3.md](docs/사용법-cores3.md).

## 누르는 곳

![화면 배치](docs/design/cores3-layout.png)

왼손에 세로로 쥐고 엄지로 누른다. USB 선은 위로 빠진다.

| 누르는 곳 | 보내는 키 | Claude 에서 |
|---|---|---|
| **Talk**(왼쪽 아래) | ⌘D | 말하기. 한 번 누르면 듣기 시작, 다시 누르면 끝 |
| **OK**(오른쪽 아래, ✓) | Enter | 보내기 · 허락 · 선택 확정 |
| **Back · Next** 짧게 | F17 · F18 | 같은 VS Code 창의 옆 패널로(VS Code 에 단축키 두 줄을 넣어야 한다) |
| **Back · Next** 길게(0.6초) | ⇧⌘\` · ⌘\` | 같은 앱의 다른 창으로 |
| **▲ ▼** | ↑ ↓ | 선택지 옮기기. 누르고 있으면 계속 간다 |
| **✕** | Esc | 취소 · 거부 · 작업 중단. 1초에 한 번만 |
| **OK + ✕** 3초 | — | 블루투스 짝 지우기 |
| 맨 위 칸(캐릭터) 톡 | — | 빨간 "듣는 중" 표시만 뒤집는다 |

처음 한 번 할 일(소리 입력 고르기 · 단축키 두 줄), 화면이 알려 주는 것, 선 없이 쓰기, Claude 의 알림 받기: [docs/사용법-cores3.md](docs/사용법-cores3.md)

## 전제와 한계 (솔직하게)

- **맥 전용이다.** 굽는 도구가 macOS 용이고, 키는 맥의 단축키(⌘D · ⌘\`)로 나간다. VS Code + Claude Code 확장(음성 받아쓰기 ⌘D 가 되는 상태)이 있어야 한다.
- **기기 마이크의 소리는 선으로만 간다.** 무선일 때 말은 맥의 마이크나 이어폰으로 한다. 선으로 쓸 때도 설정 > 사운드 > 입력에서 `vibe-stick mic` 을 골라야 기기 마이크로 말이 들어가고, 고른 동안에는 맥의 다른 프로그램(화상 회의 등)도 이 마이크로 듣는다.
- **빨간 "듣는 중" 표시에는 두 가지가 있다.** 채운 흰 점은 사실(맥이 이 기기의 마이크를 열었다)이고, 빈 고리는 어림(Talk 를 눌렀지만 맥은 이 마이크를 열지 않았다)이다. 어림은 실제와 어긋날 수 있다 — 맨 위 칸(캐릭터)을 톡 쳐서 맥 화면의 받아쓰기 표시와 같게 맞춘다.
- **M5Stack CoreS3 로 만들고 확인했다.** 배터리가 없는 CoreS3 SE 로는 확인하지 않았다.

## 준비물과 굽기

- **M5Stack CoreS3**([공식 문서](https://docs.m5stack.com/en/core/CoreS3))와 데이터가 되는 USB-C 선. 납땜은 없다.
- macOS, VS Code + Claude Code 확장
- [ESP-IDF](https://docs.espressif.com/projects/esp-idf/en/v5.5.4/esp32s3/get-started/) 5.5.x (v5.5.4 로 만들고 확인했다). `tools/flash.sh` 는 `~/esp/esp-idf-5.5.4` 에서 찾는다 — 다른 곳에 깔았으면 스크립트의 그 줄을 고친다(고치지 않으면 아무 말 없이 끝난다).

```
cd cores3 && source ~/esp/esp-idf-5.5.4/export.sh
python tools/backup.py ~/cores3-original.bin    # 처음 올리기 전에: 기기의 원래 내용을 통째로 백업
tools/flash.sh                                  # 빌드해서 굽는다(평소 판)
```

**이 세 줄만 보고 따라 하지 말 것.** 내 기기의 MAC 을 적어 두는 일, 내려받기 모드(RST 3초), 백업 확인, 다음부터 화면의 ✓ 를 꾹 눌러 받는 법까지 차례대로 적은 [docs/사용법-cores3.md](docs/사용법-cores3.md) 의 "빌드하고 올리기"를 따른다.

올린 뒤: 맥의 잠금을 푼 채 USB 로 꽂으면 맨 위에 초록 점과 `Ready` 가 뜬다. 설정 > 사운드 > 입력에서 `vibe-stick mic` 을 고른다.

## 구조

| 곳 | 맡는 일 |
|---|---|
| `cores3/main/` | 기기와 닿는 층: USB(키보드 · 마이크 · 로그 포트), 터치와 화면, 마이크, 센서, 소리 |
| `cores3/logic/` | 기기와 무관한 순수 코드 — 누름 판정, 화면 상태와 그리기, "지금 이 누름을 받아도 되는가"를 가리는 문지기들. 컴퓨터에서 시험한다 |
| `cores3/tools/` | 굽기(`flash.sh`), 백업(`backup.py`), 기기 찾기 · 명령 · 로그(`vibectl.py`), Claude 알림(`claude_note.py`), 화면 조각 만들기(`gen_art.py`) 등 |
| `cores3/test/host/` | 호스트 시험과 화면 미리보기 |
| `src/` | [조이스틱 판](https://github.com/parkds-claude/vibe-stick-public)과 함께 쓰는 코드: 입력 → 사건 → 키(`logic/input_logic.*` · `keymap.*` · `dispatch.*`), 블루투스 키보드(`ble_hid.*`), 캐릭터 점 그림(`logic/pixel_art.*`) |
| `test/host/check.h` | 호스트 시험이 쓰는 작은 CHECK·RUN 매크로(조이스틱 판과 함께 쓴다) |

설계 결정은 코드 주석에 `D번호` 로 이유 · 비용 · 되돌리는 법과 함께 적혀 있다.

## 개발

```
sh cores3/test/host/run.sh        # 호스트 시험(기기 불필요): 누름 · 화면 · 문지기 / USB 설명자 / 파이썬 도구
sh cores3/test/host/preview.sh    # 모든 장면을 그려 docs/design/cores3-screens.png 를 덮어쓴다(기기 픽셀 그대로)
```

USB 설명자 검사는 `cores3` 를 한 번이라도 빌드해 부품을 내려받은 뒤에만 돌고, 파이썬 도구 시험은 그 python3 에 pyserial 이 있을 때만 돈다(없으면 건너뛴다고 알려 준다).

둘 다 저장소 맨 위 폴더에서, git 으로 받은 사본에서 돌린다 — 도구 시험 한 건이 `*.part` 가 제외되는지를 git 에게 묻기 때문에 `.git` 이 없는 사본(ZIP 으로 받은 것)에서는 그 한 건이 실패한다.

## 마스코트

기본 마스코트는 Claude Code 의 캐릭터를 작성자가 개인용으로 픽셀로 옮긴 **비공식 팬아트**다. **MIT 라이선스에 포함되지 않는다** — 권리는 Anthropic 에 있고, 승인을 받은 것이 아니며, 요청이 있으면 제거한다(그때까지 이 저장소의 git 이력에는 남는다). **상업적으로 쓰거나 판매·배포하는 기기에 넣지 말 것** — 자체 캐릭터로 굽는다. 이 프로젝트를 위해 새로 그린 다섯(MIT)이 함께 들어 있어 빌드 때 고를 수 있다.

| 이름 | 빌드 값 | 모습 |
|---|---|---|
| 클로드 (기본) | `Claude` | 비공식 팬아트 |
| 까망이 | `Cat` | 검은 고양이 |
| 스틱이 | `Stick` | 오락실 조이스틱 |
| 키캡이 | `Keycap` | 키보드에서 빠져나온 키 |
| 삐삐 | `Robot` | 안테나 달린 로봇 |
| 새싹이 | `Sprout` | 머리에 새싹 난 찹쌀떡 |

바꾸려면 `cores3/` 에서 `idf.py -B build -DMASCOT=Cat reconfigure` 를 한 번 돌린 뒤 `tools/flash.sh` 로 올린다. 그림 데이터는 `src/logic/pixel_art.cpp` 의 글자 격자라 새 마스코트를 그려 넣기도 쉽다. 여섯 모습(자체 다섯 + 기본 캐릭터, 조이스틱 판 화면에 그린 것): [docs/design/mascots.png](docs/design/mascots.png) — 맨 아랫줄이 기본 캐릭터(팬 아트, MIT 예외)다.

(`src/logic/pixel_art.h` 의 주석에 나오는 `-DMASCOT_ID=…` 와 `test/host/preview.sh` 는 조이스틱 판의 방법이다. 이 저장소에서는 `-DMASCOT=…` 이다 — `idf.py -DMASCOT_ID=…` 는 컴파일러까지 가지 않아 기본 캐릭터로 빌드된다.)
